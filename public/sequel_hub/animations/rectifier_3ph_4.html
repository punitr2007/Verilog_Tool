3-phase rectifier

The three-phase half bridge diode rectifier given below is connected to a three-phase ac voltage source through inductor $L=1\,$mH.
  1. Plot $v_d$, the voltage across the current source.
  2. What is the average value of $v_d$?
  3. What is the power delivered to $I_s$?
  4. Find the duration for which a diode conducts in one fundamental cycle of the input voltage.
  5. Which are the dominant harmonics in the ac line current?

import gseim_calc as calc
import numpy as np

s_I0 = "10"
s_L = "1e-3"

VL = 400.0
A_sin = VL*np.sqrt(2/3)

s_A_sin = ("%11.4E"%(A_sin)).strip()

l = [
  ('$I0', s_I0),
  ('$L', s_L),
  ('$A_sin', s_A_sin),
]
calc.replace_strings_1("rectifier_3ph_4_orig.in", "rectifier_3ph_4.in", l)
print('rectifier_3ph_4.in is ready for execution')
