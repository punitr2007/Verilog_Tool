3-phase controlled rectifier

The three-phase thyristor-controlled converter given below is used to inject power from a battery storage farm to the three-phase AC supply. The terminal voltage of the battery farm is maintained at $400\,$V. A large inductance is connected in the DC circuit to maintain a ripple-free DC current of $40\,$A. Find the firing angle required. What is the RMS value of the fundamental line current for that condition?

import gseim_calc as calc
import numpy as np

s_alpha = "90" # to be changed by user
s_L = "1"
s_R = "2"

VL = 400.0
A_sin = VL*np.sqrt(2/3)

s_A_sin = ("%11.4E"%(A_sin)).strip()

l = [
  ('$alpha', s_alpha),
  ('$L', s_L),
  ('$R', s_R),
  ('$A_sin', s_A_sin),
]
calc.replace_strings_1("controlled_rectifier_3ph_5_orig.in", "controlled_rectifier_3ph_5.in", l)
print('controlled_rectifier_3ph_5.in is ready for execution')
