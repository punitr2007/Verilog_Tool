Boost Converter: DCM

The boost converter given below has an input voltage of $V_i = 5\,V$. The average output voltage is $V_o = 10\,V$, and the load resistance is $5\,\Omega$. The switching frequency is $25\,$kHz, and $C = 220\,\mu$F. Determine the value of $L$ if $I_L\,$(peak-to-peak) is $3\times I_L^{\mathrm{avg}}$.

Evaluate the following quantities:

  1. duty ratio
  2. peak-to-peak ripple voltage across the capacitor
  3. rms current through switch, diode, inductor, and capacitor

import gseim_calc as calc
s_Vin = '5'
s_L = '5.55u'
s_C = '220u'
s_R = '5'
s_D = '0.5' # to be changed by user
s_f_hz = '25e3'
l = [
  ('$Vin', s_Vin),
  ('$L', s_L),
  ('$C', s_C),
  ('$R', s_R),
  ('$D', s_D),
  ('$f_hz', s_f_hz)
]
calc.replace_strings_1("boost_dcm_1_orig.in", "boost_dcm_1.in", l)
print('boost_dcm_1.in is ready for execution')

On the output file produced by GSEIM (in this case, boost_dcm_1.dat), we can do some post-processing to obtain average and rms values, for example. For this purpose, a python module gseim_calc.py has been included in the directory from which you launched Jupyter. Run the following python script to obtain the quantities of interest listed in the question.

In [7]:
import gseim_calc as calc
import numpy as np

slv = calc.slv("boost_dcm_1.in")

i_slv = 0
i_out = 0
filename = slv.l_filename_all[i_slv][i_out]
print('filename:', filename)
u = np.loadtxt(filename)
t = u[:, 0]

IL = slv.get_array_double(i_slv,i_out,"IL",u)
IS = slv.get_array_double(i_slv,i_out,"IS",u)
ID = slv.get_array_double(i_slv,i_out,"ID",u)
IC = slv.get_array_double(i_slv,i_out,"IC",u)
v_in = slv.get_array_double(i_slv,i_out,"v_in",u)
v_out = slv.get_array_double(i_slv,i_out,"v_out",u)
clock = slv.get_array_double(i_slv,i_out,"clock",u)

# since we have stored two cycles, we need to divide the last time point
# by 2 to get the period:

T = t[-1]/2

l_IL    = calc.avg_rms_3a(t, IL,    0.0, 2.0*T, 1.0e-3*T)
l_IS    = calc.avg_rms_3a(t, IS,    0.0, 2.0*T, 1.0e-3*T)
l_ID    = calc.avg_rms_3a(t, ID,    0.0, 2.0*T, 1.0e-3*T)
l_IC    = calc.avg_rms_3a(t, IC,    0.0, 2.0*T, 1.0e-3*T)
l_v_out = calc.avg_rms_3a(t, v_out, 0.0, 2.0*T, 1.0e-3*T)

t_start = 0.0
t_end = 2.0*T

l1 = calc.min_max_1(t, IL, t_start, t_end)
IL_ptop = l1[1] - l1[0]
print('IL_ptop:', "%11.4E"%IL_ptop)

l2 = calc.min_max_1(t, v_out, t_start, t_end)
VC_ptop = l2[1] - l2[0]
print('VC_ptop:', "%11.4E"%VC_ptop)

IL_rms = l_IL[1]
print('IL_rms:', "%11.4E"%IL_rms)
IL_avg = l_IL[0]
print('IL_avg:', "%11.4E"%IL_avg)
IS_rms = l_IS[1]
print('IS_rms:', "%11.4E"%IS_rms)
ID_rms = l_ID[1]
print('ID_rms:', "%11.4E"%ID_rms)
IC_rms = l_IC[1]
print('IC_rms:', "%11.4E"%IC_rms)
Vout_avg = l_v_out[0]
print('Vout_avg:', "%11.4E"%Vout_avg)
Vout_rms = l_v_out[1]
print('Vout_rms:', "%11.4E"%Vout_rms)
