3-phase VSI

The power delivered to a balanced star connected resistive load from a 3-phase bridge inverter is 10 kW for 180-degree conduction mode. The dc source voltage is $V_{dc} = 600\,$V. For 120-degree conduction mode, what is the power delivered to the load?

We now replace the strings such as \$Vdc, \$R, with the values of our choice by running the python script given below. It takes an existing circuit file VSI_3ph_16_orig.in and produces a new circuit file VSI_3ph_16.in, after replacing \$Vdc, \$R, etc. with values of our choice.

In [3]:
import gseim_calc as calc
s_Vdc = "600"
Vdc = float(s_Vdc)

P = 10.0e3
R = (2/3)*Vdc*Vdc/P
s_f_clock = "50"
s_R = ("%11.4E"%R).strip()

phi = 120.0
D1 = phi/360.0
s_D1 = ("%11.4E"%(D1)).strip()

f_clock = float(s_f_clock)
T = 1/f_clock
s_2T = ("%11.4E"%(2.0*T)).strip()

l = [
  ('$Vdc', s_Vdc),
  ('$R', s_R),
  ('$D1', s_D1),
  ('$2T', s_2T),
  ('$f_clock', s_f_clock),
]
calc.replace_strings_1("VSI_3ph_16_orig.in", "VSI_3ph_16.in", l)
print('VSI_3ph_16.in is ready for execution')
