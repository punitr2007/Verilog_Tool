3-phase rectifier

The three-phase diode rectifier given below is connected to a three-phase ac voltage source.
  1. Plot $v_o$, diode current, and ac source current.
  2. What is the duration for which a diode conducts in one fundamental cycle of the input voltage?
  3. What is the average value of $v_o$?
  4. What is the peak-to-peak ripple voltage across $R$?
  5. Find the RMS values of the diode current and ac line current.
  6. What is the power delivered to the load?
  7. What is the RMS value of the fundamental component of the ac line current?
  8. Compute the THD of the ac line current.
  9. Find the input power factor.
  10. Which are the dominant harmonics in the ac line current?

import gseim_calc as calc
import numpy as np

s_R = "100"

VL = 400.0
A_sin = VL*np.sqrt(2/3)

s_A_sin = ("%11.4E"%(A_sin)).strip()

l = [
  ('$R', s_R),
  ('$A_sin', s_A_sin),
]
calc.replace_strings_1("rectifier_3ph_6_orig.in", "rectifier_3ph_6.in", l)
print('rectifier_3ph_6.in is ready for execution')

slv = calc.slv("rectifier_3ph_6.in")

i_slv = 0
i_out = 0
filename = slv.l_filename_all[i_slv][i_out]
print('filename:', filename)

t1 = u1[:, 0]

v_o = slv.get_array_double(i_slv,i_out,"v_o",u1)
ID1 = slv.get_array_double(i_slv,i_out,"ID1",u1)
ID2 = slv.get_array_double(i_slv,i_out,"ID2",u1)

# compute Fourier coeffs:

t_start = T 
t_end = 2.0*T

n_fourier = 20

coeff_ISa, thd_ISa = calc.fourier_coeff_1C(t1, ISa, 
    t_start, t_end, 1.0e-8, n_fourier)

coeff_v_o, thd_v_o = calc.fourier_coeff_1C(t1, v_o, 
    t_start, t_end, 1.0e-8, n_fourier)

print('THD in ac line current:', "%5.2f"%(thd_ISa*100.0), "%")
print("ac line current fundamental: RMS value: ", "%11.4E"%(coeff_ISa[1]/np.sqrt(2.0)))

x = np.linspace(0, n_fourier, n_fourier+1)

y_v_o = np.array(coeff_v_o)
y_ISa = np.array(coeff_ISa)
