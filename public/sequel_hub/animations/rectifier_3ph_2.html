3-phase half-bridge rectifier

The three-phase half bridge diode rectifier given below is connected to a three-phase ac voltage source. The magnitude of the current source is $10\,$A.
  1. Plot the voltage $v_d$ and current through the diodes.
  2. Find the average and RMS values of the voltage across $Is$.
  3. What is the power delivered to $Is$?
  4. Find the RMS values of the diode currents.
  5. Find the RMS value of the fundamental component of the ac line current.
  6. What is the angle between the phase voltage $V_{an}(t)$ and line current?
  7. Find the input power factor.
  8. What is the THD of the input current?
  9. Which are the dominant harmonics in the ac line current?

import gseim_calc as calc
import numpy as np

s_I0 = "10"

VL = 400.0

s_A_sin = ("%11.4E"%(A_sin)).strip()

l = [
  ('$I0', s_I0),
  ('$A_sin', s_A_sin),
]
calc.replace_strings_1("rectifier_3ph_2_orig.in", "rectifier_3ph_2.in", l)
print('rectifier_3ph_2.in is ready for execution')

import numpy as np
import matplotlib.pyplot as plt 
import gseim_calc as calc
from setsize import set_size

f_hz = 50.0
T = 1.0/f_hz

slv = calc.slv("rectifier_3ph_2.in")

i_slv = 0
i_out = 0
filename = slv.l_filename_all[i_slv][i_out]
print('filename:', filename)
u1 = np.loadtxt(filename)
t1 = u1[:, 0]

v_d = slv.get_array_double(i_slv,i_out,"v_d",u1)
ID1 = slv.get_array_double(i_slv,i_out,"ID1",u1)
ID2 = slv.get_array_double(i_slv,i_out,"ID2",u1)
ID3 = slv.get_array_double(i_slv,i_out,"ID3",u1)

# get A_sin from the circuit file:
fin = open("rectifier_3ph_2.in", "r")
for line in fin:
    if 'name=Vsa' in line:
        for s in line.split():
            if s.startswith('a='):
                A_sin = float(s.split('=')[1])
fin.close()

# compute Fourier coeffs:

t_start = T 
t_end = 2.0*T
n_fourier = 20

coeff_ID1, thd_ID1, coeff_a_ID1, coeff_b_ID1 = calc.fourier_coeff_2A(
  t1, ID1, t_start, t_end, 1.0e-8, n_fourier)

t_ID1, y_ID1 = calc.construct_fourier_component(1, coeff_a_ID1, coeff_b_ID1, 0.0, T, 2, 200)

omg = f_hz*2.0*np.pi
vs_a = A_sin*np.sin(omg*t_ID1)

theta1 = math.atan2(-coeff_b_ID1[1], coeff_a_ID1[1])*180.0/math.pi

# if ID1 was written as k * sin (w*t + theta), what would theta be?
theta = theta1 + 90.0
print('angle of i_a w.r.t. V_a:', "%11.4E"%theta)

color1='green'
color2='crimson'
color3='cornflowerblue'

ax[1].plot(t_ID1*1e3, vs_a, color=color3, linewidth=1.0, label="$V_a$")
